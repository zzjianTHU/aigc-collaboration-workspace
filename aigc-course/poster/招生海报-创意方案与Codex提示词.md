## 一、核心创意：把招生海报做成一张「电影首映海报」

**一句话概念：这门课本身就是一部电影，两位老师是「监制」，导演一栏写的是——你。**

为什么这样做：

- 课程叫「未来导演计划」，最后学生真的要交一支 60 秒短片、办结课影展。电影海报是最贴题的视觉语言。
- 高中生对「电影海报」的识别度和好感度远高于「培训班海报」，转发意愿也更高。
- 电影海报底部那一块密密麻麻的「片尾字幕块」（billing block），正好用来放课时、人数、成果这些报名信息，既装得下信息，又不像广告。
- 「导演：你」这个梗一眼就懂，把报名动作变成了「来当导演」。

### 画面结构（竖版 2:3，自上而下）

| 区域 | 占比 | 内容 |
| --- | --- | --- |
| 顶部条 | 约 6% | 左：`FUTURE DIRECTORS PROGRAM`；右：`2026 · 冬季招生`；中间一行细小的电影胶片齿孔 |
| 主视觉 | 约 52% | 两位老师半身像左右并排，略微错位（左人略高、右人略低），像双主演电影海报；身后是一块巨大的、正在投影的银幕光，光里有像素点和噪点慢慢「去噪」成画面的效果（呼应课程里讲的扩散模型原理） |
| 取景器元素 | 叠在主视觉上 | 每位老师外面有一个很细的相机取景框（四角括号 + 对焦十字），左上角红点 `● REC`，下角小字 `CREATOR_01` / `BUILDER_02`（沿用课程介绍页的设定） |
| 主标题区 | 约 18% | 大字：`未来导演计划`；副标：`AIGC 影像创作课`；一行 slogan：`看懂智能，驾驭影像，成为讲述未来的人` |
| 讲师名牌 | 约 8% | 两位老师名字下方各一行头衔（见文案） |
| 片尾字幕块 | 约 10% | 电影海报式的窄长瘦体字信息块，含「导演：你」 |
| 报名区 | 约 6% | 右下留空白方块放二维码（后期贴真二维码），左侧「扫码报名 · 每班限 12 人」 |

### 色调与质感

- 沿用课程介绍页的配色：**近黑深蓝底 + 暖琥珀色主光 + 冷蓝轮廓光**。人物统一使用暖琥珀主光与冷蓝轮廓光。
- 质感：电影胶片颗粒、轻微光晕（halation）、银幕投影的体积光。高级、克制，不要科幻霓虹、不要满屏机器人和电路板。
- 字体气质：主标题用粗黑体或宋黑混排的电影片名字；英文用窄长无衬线体（类似电影海报 credits 字体）。

### 两位老师怎么处理（重点）

- **必须保留真人五官与神态**，不能被「美化」成另一个人。用参考图模式（图生图 / 编辑），保真度调到最高。
- **统一造型**：两张原图服装风格差别很大（马老师浅色上衣、颈挂黑色耳机，赵老师白衬衫领带、拿饮料）。建议统一成深色休闲上装，打同一套光，看起来像同一张海报拍的。
- **赵老师的照片**：手里的杯子印着海绵宝宝，这是有版权的卡通形象，**招生海报不要出现**。两个处理办法（二选一，推荐 A）：
  - A：保留「拿杯子吸管」的俏皮姿势，但杯子改成纯色、无图案的饮料杯；
  - B：改成手持一块电影场记板，更贴课程主题。
- **马老师的照片**：保留颈挂黑色耳机、侧向凝视的姿态，严格依照用户确认的新照片。不得使用旧版戴帽子举相机的人物。
- 两人姿势形成「一动一静、一俏皮一专业」的对比，这是海报的人情味来源。
